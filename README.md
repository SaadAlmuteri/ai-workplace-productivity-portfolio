# AI Workplace Productivity Portfolio — Project Coordinator

## Project Overview
This repository serves as a professional capstone portfolio demonstrating the practical application of Generative AI tools in workplace operations. Focused on the role of a **Project Coordinator**, it showcases structured prompt engineering, rigorous human-in-the-loop review workflows, data extraction from messy communications, milestone planning, and strict verification protocols to boost operational productivity while maintaining data privacy and accuracy.

## Selected Workplace Scenario
**Role:** Project Coordinator (Operations & Digital Initiatives)  
**Context:** Managing day-to-day project communications, tracking task dependencies, synthesizing updates from technical cross-functional teams, planning project phases, and drafting executive status reports for stakeholders.

## Course Skills Demonstrated
- **Prompt Engineering:** Designing structured, reusable prompts using **C.A.R.E.** and **R.C.T.O.** frameworks, along with Few-Shot prompting techniques.
- **Executive Writing Workflow:** Executing the 4-step workflow (Draft → Verify → Refine → Human Sign-off).
- **Information Synthesis:** Transforming unstructured meeting notes into actionable, prioritized decision briefs.
- **Planning Chain:** Deconstructing high-level strategic goals into actionable mechanisms, phases, and tasks.
- **Verification Protocol:** Implementing a 4-step verification checklist to validate AI-generated facts, figures, and assumptions.
- **Responsible AI:** Enforcing data classification standards (Green/Amber/Red) and mitigating bias and hallucinations.

## Key Learnings
1. **Context is King:** The difference between a mediocre and an outstanding AI output lies in structured constraints (Role, Context, Expected Output) rather than lengthy conversational instructions.
2. **AI as an Accelerator, Human as the Owner:** Generative AI provides a rapid first draft, but human review and factual verification remain irreplaceable for accountability.
3. **Structured Information Prevents Hallucination:** Constraining AI to work only with provided text (e.g., using `[Not Specified]` rules) completely eliminates fabricated details.
4. **Data Hygiene First:** Classifying information before prompting protects organizational integrity and adheres to data privacy standards.
